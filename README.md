# 🎬 Netflix AI Dashboard

An interactive data dashboard built on the Netflix Movies & TV Shows dataset using Python and Plotly.

## 📊 Features
- Dataset Overview & Data Cleaning
- Key Metrics (KPIs): Total titles, Movies vs TV Shows, Countries, Genres
- 6 Interactive Visualizations:
  - Movies vs TV Shows (Donut Chart)
  - Top 10 Countries by Content
  - Content Added Over the Years
  - Top 10 Genres
  - Content Ratings Distribution
  - Movie Duration Distribution

## 🛠️ Tech Stack
- Python
- Pandas
- NumPy
- Plotly
- Google Colab

## 📁 Dataset
[Netflix Movies and TV Shows – Kaggle](https://www.kaggle.com/datasets/shivamb/netflix-shows)

## ▶️ How to Run
1. Open `netflix_dashboard.ipynb` in Google Colab
2. Run all cells in order
3. The dashboard will render inline and export as `netflix_dashboard.html`
